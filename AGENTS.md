
- Client connections made in-app are stored as localStorage overrides in `src/lib/clientSource.ts` (`connectClientSource`) and read before seed data — so Edit Engagement detects new connections without a backend.
- Create/Edit Engagement and Clients share SourceConnectionModal and provider metadata so the prototype selection, loading, confirmation and persistence remain consistent without real OAuth.
- The demo seed (`seedDemoEngagementMeta` in `src/store/engagementsStore.ts`) must not overwrite a user-saved `dataSource`/`sourceProvider`/`sourceYears`/`sourceRollForward` on reload — it only applies defaults when the user never saved one, so per-year Data Source selections in Edit Engagement persist.
- Trial Balance per-year data presence lives in `src/lib/tbYearData.ts`: a year shows data only if the engagement is seeded, the year is Source, or a per-year upload marker exists — so new CSV years start empty without a backend.
- A roll forward of a First Year of Operations file marks PY2 as `priorYearSources.py2 = "nodata"` while `yearDataSources` stays `csv | source`; Edit Engagement and Trial Balance read that marker to show "No data" — so the existing per-year source type didn't need a third value.
- First Year of Operations roll forwards carry `fyoChainYear` (1→2→3, then Full year); Edit Engagement and Trial Balance derive visible years from it (and hide a "nodata" PY2) — so FOO stays locked until all three years are full without a new period-type value.
- CreateEngagement shares one original-versus-current year-source predicate across its form connection requirement and save-button connection blockers so unchanged Edit sources receive the same exception in both checks.
- Client connections carry a `connectionId` (new on each connect/provider switch, kept when re-confirming the same live connection); engagements save `sourceConnectionId`, and Edit marks saved rows on an older same-provider connection as `source:<provider>|prev` — so a same-source reconnect reuses the provider-switch flow without a new row type.
